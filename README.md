# Palworld Font Customizer

Palworld 全局单字体替换工具。字体转换与 Pak 生成均在本机离线完成，不会上传用户字体。

## 功能

- 支持包含完整简体中文字库的静态 TTF/OTF。
- 支持 Variable Font，并根据字体提供的可变轴显示调节控件。
- 自动查找 Steam 与 Steam Library 中的 Palworld。
- 未自动找到时，可点击游戏状态手动选择安装文件夹。
- 安装与还原前检测 Palworld 是否正在运行。
- 替换和移除字体 Pak 前自动创建并校验备份。

## 使用

1. 选择或拖入字体。
2. 如果是 Variable Font，可调整字重及其余可变参数。
3. 完全退出 Palworld 后点击“应用”。
4. 如需恢复游戏原始字体，退出游戏后点击“还原默认”。

第三方组件及许可证见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
